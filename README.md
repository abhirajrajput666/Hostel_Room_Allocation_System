# 🏨 Hostel Room Allocation System

## 📌 Project Description

The **Hostel Room Allocation System** is a Java console-based application used to manage hostel student records, room allocation, and fee management.
It helps administrators store, update, search, and manage student details along with room and bed assignments.

---

## 🎯 Features

* Add new student and allocate room
* Automatic bed allocation
* Search student by **ID or Name**
* Update student details
* Deallocate student
* Monthly fee management
* Fee history tracking

---

## 🧠 Java Concepts Used

* Object-Oriented Programming (OOP)
* Classes and Objects
* Constructors
* File Handling
* Exception Handling
* Arrays and Loops

---

## 🛠 Technologies Used

* **Language:** Java
* **IDE:** VS Code / IntelliJ / Eclipse
* **Storage:** Text Files (`students.txt`, `fees.txt`)
* **Type:** Console Application

---

## 🚀 How to Run

1. Install **Java JDK**
2. Compile the project

```
javac *.java
```

3. Run the program

```
java HostelRoomAllocationSystem
```
